GETTING STARTED

From zero to your first gated app in about five minutes.

1. Get the APK

Easiest — grab it from CI. Open the android-v2 CI workflow → click the latest successful run → download the sonder-v2-debug-apk artifact → unzip and you have app-debug.apk.

Or grab a tagged release. The Releases page has the latest build as sonder-v2-<version>.apk — already signed, so it installs the same way.

DON'T MIX CI AND RELEASE BUILDS

The CI debug APK and the Release APK may use different signing keys — the Release APK is signed with the project keystore, the CI one with the Android debug key. Android refuses to install one over the other (INSTALL_FAILED_UPDATE_INCOMPATIBLE). Switching between them requires uninstalling first, which deletes all app data.

Or build it yourself (JDK 17 + Android SDK platform 37):

cd android-native
./gradlew assembleDebug

2. Install

Copy the APK to your phone and open it. Android will ask you to allow installs from that source once — approve it, continue, install.

3. Onboard (four permissions)

Sonder needs four permissions to enforce anything. Onboarding walks you through all of them with a one-line "why" and a button that deep-links straight to the right settings page:

PermissionWhy it's needed
AccessibilityKnows which app just came to the foreground, and reads view identifiers to spot Reels, Shorts and Stories. Those are developer-chosen resource names — never screen content.
Display over other appsShows the block screen the instant a limited app opens.
Usage accessThe fallback that says which app is in front when accessibility is slow.
NotificationsTells you when an app's bank runs dry.

FINICKY ACCESSIBILITY?

Accessibility state can lag right after you enable it. Sonder waits 10 seconds after each app open before checking — if something is still missing, a pixel-styled popup appears with direct links. Grant, come back, done.

4. Pick your first target

Open TARGETS in the bottom dock and tap ADD, then search for an app (YouTube is a classic first victim) and check it. A limited app now requires a won hand to open.

Each row in the list is inert: its one control is the › arrow, which opens that app's own settings — its maximum bank, its scope, and the SAVE and REMOVE LIMIT buttons. SAVE asks you to press it twice, thirty seconds apart, so a rule cannot be changed in a hurry.

5. Play your first hand

Leave Sonder, open the target app. The block screen appears immediately — tap it to enter the gate:

  1. Pick a chip — 2:00, 5:00, 10:00, or ALL IN for the whole bank.
  2. DEAL HAND — you get two cards, dealer shows one.
  3. HIT to draw, STAND to hold.
  4. Beat the dealer without busting → CONTINUE → you're dropped straight into the app with your winnings banked.

Lose, and the stake comes off the bank — never below zero. The bank backs the bet, so a chip you cannot cover is greyed out, and a bank spent down to nothing is a gate with no hand on it until the next morning, when every bank opens with the 2:00 chip again. Full arithmetic: Access rules.

6. Verify it's enforcing

While you're in the banked app, press home, make a coffee, come back after more than a minute — the bank is still what you left it at, because only time in the app is billed. Watch it tick: open the app for a minute, leave for two, and come back to a bank one minute lighter.

Troubleshooting

GATE DIDN'T APPEAR

Check Settings → all four permissions OK? Then check your OEM's battery manager hasn't suspended Sonder (see the battery manager guide). Re-check after any Sonder update — Android sometimes disables accessibility services on app updates.

NO BLOCK OVERLAY, ONLY A DELAYED GATE

The overlay permission is off. The gate still works, just slower. Fix it in onboarding or Settings.
