Data schema

  • TargetEntity — package, enabled flag, added-at
  • GrantEntity — package, endAtMillis, lastSeenMillis
  • LockoutEntity — package, untilMillis, debtMillis
  • HandHistoryEntity — timestamp, result, debt delta (Stats screen)

All times are absolute epoch millis — timers keep running across process death, reboots, and Doze.

Detection and the absence rule

The accessibility service watches window-state changes only (TYPE_WINDOW_STATE_CHANGED), filtered to target packages, self, system dialogs, and notifications. Events are debounced; each accepted event updates lastSeenMillis for the package. A window event after a gap longer than the absence threshold triggers revocation (rules → timers).
