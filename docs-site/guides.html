Verify enforcement on-device

Debug builds shorten the timers so the whole loop fits in a minute:

ConstantReleaseDebug
Access window (win)5 min1 min
Absence revocation>60 s>20 s
 
# with a debug APK installed:
# 1. open a target app → gate appears
# 2. win a hand → app opens with a 60s clock
# 3. leave the app, return after 25s → grant revoked
# 4. lose a hand, close the gate → lockout timer shows
# 5. reopen the target → gate appears again (lockout) or debt screen

Watch the state badges on Home: ✓ GRANTED ♠ PLAYING ▣ LOCKED ⌛ COOLDOWN.

Add or remove targets

  1. Open TARGETS from the dock.
  2. Use the ALL / LIMITED tabs and the search field to find an app.
  3. Tap the row to toggle. ON = opening requires a won hand.

Sonder itself

Sonder excludes itself from the picker — you can't gate the gatekeeper. The system launcher and settings are also ignored by the detector so you can always reach the controls.

Work off debt (or don't)

  • Keep gambling: each win removes 10 minutes. Fastest route back in.
  • Walk away: the debt becomes a lockout that ticks down in real time.
  • Cap: debt maxes at 60 minutes. Extra losses at the cap change nothing — the cap is a mercy, not a magnet.

Exact arithmetic: Access rules → debt model.

Survive OEM battery managers

Xiaomi, Samsung, Huawei, and friends suspend background services. If the gate stops appearing after a day or two:

  1. Exclude Sonder from battery optimization (Settings → Apps → Sonder → Battery → Unrestricted).
  2. Disable "battery optimization" for the accessibility service if your OEM splits it out.
  3. Lock Sonder in the recents screen where supported.
  4. After any Sonder update, re-check accessibility — Android may have dropped it.

Reset Sonder state

Debt, grants, lockouts, and hand history live in a local Room database. To start over: Android Settings → Apps → Sonder → Storage → Clear data. That's also the honest way to cheat — which is why targets are chosen once and meant to be kept.
